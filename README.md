# نظام إدارة النتائج

تطبيق ويب تفاعلي لإضافة بيانات الطلاب وعرض نتائجهم وتفعيل لجنة الرأفة للدرجات المتوسطة. يعمل حاليًا كتطبيق واجهة أمامية ويحفظ البيانات محليًا في المتصفح.

## التقنيات المستخدمة

- HTML5
- Bootstrap 5
- CSS3
- JavaScript
- Private Fields و Encapsulation
- DOM و Try/Catch و Array Methods
- ES Modules واختبارات Node.js المدمجة

## تشغيل المشروع

1. افتح مجلد المشروع.
2. شغل خادمًا ثابتًا:

```powershell
npx serve .
```

3. افتح المتصفح على:

```text
http://localhost:5500
```

يُفضّل تشغيل التطبيق عبر خادم محلي لأن JavaScript يستخدم ES Modules.

## آلية الاستخدام

1. أدخل اسم الطالب وثلاث درجات ونسبة الحضور.
2. اضغط **إضافة طالب**.
3. تظهر الأخطاء داخل صندوق التنبيه الأحمر عند إدخال بيانات ناقصة أو خارج النطاق 0 إلى 100.
4. اضغط **تفعيل لجنة الرأفة** لعرض الطلاب الذين متوسطهم من 40 إلى 49، وإضافة 5 درجات لكل منهم وإيجاد المتوسط العام بعد الرأفة.
5. تحفظ بيانات الطلاب في المتصفح تلقائيًا ويمكن حذف طالب منفرد أو مسح القائمة كاملة.
6. استخدم **تصدير نسخة** لحفظ ملف JSON، و**استيراد نسخة** لاستعادة قائمة من ملف احتياطي. الاستيراد يستبدل القائمة الحالية بعد التأكيد.

## الاختبارات

يتطلب تشغيل الاختبارات Node.js:

```powershell
node --test
```

## ملاحظات

- التخزين محلي في المتصفح والجهاز الحالي، وليس قاعدة بيانات مشتركة أو آلية مصادقة.
- يحتوي `js/main.js` على كلاس `Student` وتفاعل الواجهة، ويفصل `js/student.js` التقارير والنسخ الاحتياطي عن التخزين المحلي في `js/studentRepository.js`؛ يمكن استبدال طبقة التخزين باتصال API عند إضافة خادم.
