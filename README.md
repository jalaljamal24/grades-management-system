# نظام إدارة النتائج

تطبيق ويب تفاعلي لإضافة بيانات الطلاب وعرض نتائجهم وتفعيل لجنة الرأفة للدرجات المتوسطة.

## التقنيات المستخدمة

- HTML5
- Bootstrap 5
- CSS3
- JavaScript
- Private Fields و Encapsulation
- DOM و Try/Catch و Array Methods

## تشغيل المشروع

1. افتح مجلد المشروع.
2. شغل خادمًا ثابتًا:

```powershell
python -m http.server 5500
```

3. افتح المتصفح على:

```text
http://localhost:5500
```

بديلًا، يمكن فتح `index.html` مباشرة في المتصفح إذا كانت الإعدادات تدعم ذلك.

## آلية الاستخدام

1. أدخل اسم الطالب وثلاث درجات ونسبة الحضور.
2. اضغط **إضافة طالب**.
3. تظهر الأخطاء داخل صندوق التنبيه الأحمر عند إدخال بيانات ناقصة أو خارج النطاق 0 إلى 100.
4. اضغط **تفعيل لجنة الرأفة** لعرض الطلاب الذين متوسطهم من 40 إلى 49، وإضافة 5 درجات لكل منهم وإيجاد المتوسط العام بعد الرأفة.
